# 📈 Sales & Demand Forecasting for Businesses

This project builds a **Machine Learning sales forecasting system** using real retail transaction data.
It predicts future product demand based on historical sales trends.

This project was developed as part of **Machine Learning Task 1 – Future Interns (2026)**.

---

# 📊 Project Objective

The goal of this project is to forecast future product demand using historical business data.

Sales forecasting helps businesses:

* Plan inventory levels
* Manage supply chains
* Prepare staffing requirements
* Reduce overstocking and shortages
* Make data-driven business decisions

---

# 📁 Dataset

This project uses the **Online Retail Dataset**, which contains real retail transaction data.

### Key Columns

| Column      | Description                  |
| ----------- | ---------------------------- |
| InvoiceNo   | Transaction number           |
| StockCode   | Product identifier           |
| Description | Product name                 |
| Quantity    | Number of items sold         |
| InvoiceDate | Date and time of transaction |
| UnitPrice   | Price of each product        |
| CustomerID  | Unique customer ID           |
| Country     | Customer location            |

The dataset is aggregated into **daily sales demand** before training the forecasting model.

# ⚙️ Project Workflow

### 1️⃣ Data Loading

The dataset is loaded from an **Excel file** using Pandas.

### 2️⃣ Data Cleaning

The dataset is cleaned by:

* Removing missing values
* Removing invalid transactions (negative quantities)
* Converting dates into proper datetime format

### 3️⃣ Data Aggregation

Transaction data is aggregated into **daily sales demand**.

This converts individual transactions into a time-series dataset.

### 4️⃣ Feature Engineering

Time-based features are created from the date column:

* Year
* Month
* Day
* Numerical day index for machine learning

### 5️⃣ Historical Sales Visualization

A line chart is generated to show **past sales trends over time**.

### 6️⃣ Model Training

A **Linear Regression model** is trained using historical demand data.

### 7️⃣ Model Evaluation

Model performance is evaluated using:

**Mean Absolute Error (MAE)**

This measures how close predicted values are to actual demand.

### 8️⃣ Demand Forecasting

The trained model predicts **future product demand for upcoming days**.

### 9️⃣ Forecast Visualization

A visualization compares:

* Actual historical sales
* Forecasted future demand

### 🔟 Output Generation

Future predictions are saved as a CSV file for further analysis.
